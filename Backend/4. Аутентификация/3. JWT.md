1. Пользователь вводит логин и пароль.
2. Сервер выдаёт два токена:
    1. `access token` — короткий пропуск.
    2. `refresh token` — ключ для получения нового пропуска.
3. `Access token` живёт примерно 15 минут.
4. Браузер отправляет его с каждым запросом HTTP:
```
GET /profile
Cookie: access_token=...
```
5. Сервер проверяет токен и понимает, какой пользователь делает запрос.
6. Когда `access token` закончился, браузер отправляет `refresh token`.
7. Сервер выдаёт новый `access token`.
8. Пользователю не нужно снова вводить пароль.
