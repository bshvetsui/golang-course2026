1. **Singleton** — один экземпляр объекта на всё приложение. Пример: один `pgxpool.Pool`, Kafka producer, logger, config.

2. **Factory Method** — создание конкретной реализации спрятано в функции/методе. Бизнес-код работает через интерфейс. Пример: `NewProducer("kafka") → KafkaProducer`, `NewRepository("postgres") → PostgresRepository`.
```go
type Producer interface {
	Send([]byte) error
}

func NewProducer(kind string) Producer {
	switch kind {
	case "kafka":
		return NewKafkaProducer()
	default:
		return NewMockProducer()
	}
}
```

3. **Abstract Factory** — создаёт сразу семейство связанных объектов. Например `ProdFactory → PostgresRepository + KafkaProducer + RedisCache`, а `TestFactory → MemoryRepository + MockProducer + MemoryCache`.
```text
ProdFactory → PostgreSQL + Kafka + Redis
TestFactory → MemoryDB + MockKafka + MemoryCache
```

4. **Prototype** — новый объект создаётся копированием уже настроенного. Например базовый конфиг Kafka/HTTP-клиента копируется и меняются только `topic`, `timeout`, `retries`.
```go
orders := baseConfig
orders.Topic = "orders"

users := baseConfig
users.Topic = "users"
```

5. **Object Pool** — набор дорогих объектов переиспользуется вместо постоянного создания. Главный пример — `pgxpool`: запрос берёт готовое соединение → делает SQL → возвращает соединение обратно.
```text
request → pgxpool → connection → PostgreSQL → обратно в pool
```
Также: `database/sql`, `sync.Pool`, HTTP connection pool.  

6. **Lazy Initialization** — объект создаётся только при первом использовании. Например Kafka producer или внешний API client создаётся не при старте сервиса, а когда впервые понадобился.
```go
once.Do(func() {
	producer = NewKafkaProducer()
})
```

7. **Multiton** — несколько Singleton-объектов, по одному на ключ. Например отдельный `pgxpool` для каждого tenant или Kafka client для каждого региона.
```text
tenant-a → pool A
tenant-b → pool B
tenant-a → снова pool A
```
