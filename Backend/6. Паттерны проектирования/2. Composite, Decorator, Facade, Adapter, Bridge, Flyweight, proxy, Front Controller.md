1. **Composite (Компоновщик)** — позволяет работать с одним объектом и группой объектов одинаково. В Go это полезно для деревьев: файлы/папки, AST, дерево роутов, меню, permissions. **Запомнить:** один интерфейс для элемента и группы элементов.
   
2. **Decorator (Декоратор)** — оборачивает объект и добавляет поведение, не меняя его. Самый частый пример в Go — middleware: logging, auth, metrics, tracing, gzip. **Запомнить:** `обёртка вокруг объекта`.
   
3. **Facade (Фасад)** — даёт простой метод поверх нескольких сложных действий. Например `CreateOrder` внутри может валидировать данные, писать в БД, отправлять событие и уведомление, а handler просто вызывает один метод. **Запомнить:** `одна простая точка вместо кучи внутренней логики`.
   
4. **Adapter (Адаптер)** — подгоняет чужой интерфейс под тот, который нужен твоему приложению. Например у тебя есть общий `Sender`, а Telegram, Slack и email имеют разные API — для каждого делаешь адаптер. **Запомнить:** `переходник между несовместимыми интерфейсами`.
   
5. **Bridge (Мост)** — отделяет основную логику от конкретной реализации. Например сервис работает с абстракцией `Storage`, а реализация может быть S3, локальный диск или GCS. В Go это часто просто интерфейс + dependency injection. **Запомнить:** `что делаем отдельно от того, как именно делаем`.
   
6. **Flyweight (Приспособленец)** — общие тяжёлые данные не копируются в каждый объект, а переиспользуются. Например тысячи пользователей могут ссылаться на один объект роли с одинаковыми permissions. В обычном Go backend встречается не так часто. **Запомнить:** `один общий объект вместо множества одинаковых копий`.
   
7. **Proxy (Заместитель)** — объект стоит перед настоящим сервисом и контролирует доступ к нему. Например сначала проверяет cache, права, rate limit или делает lazy loading, а потом уже вызывает настоящий сервис. **Запомнить:** `посредник перед реальным объектом`.

8. **Front Controller (Единая точка входа)** — все HTTP-запросы сначала попадают в одно место, которое решает, куда их отправить. В Go это router / `ServeMux` / chi / gin router. **Запомнить:** `одна входная дверь для HTTP`.
