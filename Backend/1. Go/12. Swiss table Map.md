В Go 1.24+ `map` использует Swiss Tables — открытую адресацию с группами по 8 слотов.
## Структура map
Map состоит из нескольких таблиц. Каждая таблица разбита на группы, а каждая группа содержит:
1. 8 слотов для ключей и значений;
2. 8 байт метаданных — `control word`;
3. по одному `control byte` на каждый слот.

`Control byte` показывает состояние слота:
1. `empty` — слот пуст;
2. `deleted` — элемент удалён;
3. `full` — слот занят и содержит часть хеша `h2`.

## Разделение хеша

Хеш ключа делится на две части:
1. `h1` — определяет начальную группу;
2. `h2` — используется для фильтрации слотов внутри группы.
## Поиск
1. Вычисляется хеш ключа.
2. По `h1` выбирается начальная группа.
3. `h2` сравнивается сразу с метаданными всех 8 слотов.
4. Полный ключ проверяется только в совпавших слотах.
5. Если ключ не найден, probing переходит к следующей группе.

Сравнение метаданных выполняется через SIMD или битовые операции, поэтому 8 слотов проверяются почти одновременно.
Если найден `empty`-слот, ключа в map нет. `Deleted`-слот поиск не останавливает.
## Вставка и удаление
При вставке используется первый подходящий `empty` или `deleted`-слот. Если таблица сильно заполняется, она увеличивается или разделяется.

При удалении слот может помечаться как `tombstone`, чтобы не разорвать probing-последовательность. Позже этот слот можно использовать повторно.

## Почему это быстро
1. Данные лежат рядом в памяти — хорошая `cache locality`.
2. Сразу проверяется группа из 8 слотов.
3. Полные ключи сравниваются только у подходящих кандидатов.
4. Нет отдельных overflow-бакетов.
5. Рост затрагивает отдельную внутреннюю таблицу, а не всю map.
# Коллизии

Коллизия возникает, когда два разных ключа получают одинаковую позицию в хеш-таблице.
## Способы обработки коллизий

1. **Separate Chaining** — элементы с одинаковым индексом хранятся в цепочке. Подход простой, но требует дополнительных указателей и ухудшает `cache locality`.
2. **Open Addressing** — все элементы хранятся в одном массиве. При коллизии выполняется `probing` — поиск другого подходящего слота.
