## SELECT / FROM / WHERE / LIKE / LIMIT
```sql
SELECT name, age -- * значит по всем колонкам
FROM users
WHERE age >= 18
LIMIT 10;
```
1. `SELECT` — какие колонки получить.
2. `FROM` — из какой таблицы.
3. `WHERE` — фильтр строк.
4. `LIMIT` — максимум строк.
### LIKE 
```sql
WHERE name LIKE 'Alex%'   -- начинается с Alex
WHERE name LIKE '%Alex'  -- заканчивается на Alex
WHERE name LIKE '%Alex%'  -- содержит Alex
WHERE name LIKE 'A_ex'    -- _ = один любой символ
```
`ILIKE` в PostgreSQL — тоже самое без учёта регистра.
# JOIN - соединяет строки из нескольких таблиц по условию.
```sql
SELECT users.name, orders.price
FROM users
JOIN orders ON users.id = orders.user_id;
```
1. `INNER JOIN` / `JOIN` — только строки, где совпадение есть в обеих таблицах.
2. `LEFT JOIN` — все строки слева + совпадения справа; если совпадения нет → `NULL`.
3. `RIGHT JOIN` — все строки справа + совпадения слева.
4. `FULL OUTER JOIN` — все строки обеих таблиц; где пары нет → `NULL`.
5. `CROSS JOIN` — каждая строка первой таблицы × каждая строка второй.

`OUTER JOIN` — не отдельный тип: это общее название `LEFT/RIGHT/FULL OUTER JOIN`
# GROUP BY / агрегаты - объединяет строки в группы и позволяет считать статистику по каждой группе.
```sql
SELECT country, COUNT(*)
FROM users
GROUP BY country;
```
1. `COUNT(*)` — количество.
2. `SUM(price)` — сумма.
3. `AVG(price)` — среднее.
4. `MIN(price)` — минимум.
5. `MAX(price)` — максимум.
6. `STRING_AGG(name, ', ')` — собрать значения в одну строку. - редко
```sql
SELECT
    country,
    COUNT(*) AS users,
    AVG(age) AS avg_age
FROM users
GROUP BY country;
```
## HAVING — фильтрует группы **после GROUP BY**.
отличается от `WHERE` — он фильтрует строки **до группировки**.   
```sql
SELECT country, COUNT(*)
FROM users
WHERE age >= 18
GROUP BY country
HAVING COUNT(*) >= 100;
```
