errors.New("fail") != errors.New ("fail") // каждый вызов - новое значение, они не равны

## defer func()
Отложенный вызов функции, которая выполнится перед уходом из текущей, несколько defer() подряд будут выполняться в обратном порядке (LIFO) ДАЖЕ ПРИ panic()
НЕЛЬЗЯ ДОПУСКАТЬ defer в цикле - она забивает горутину  
## panic() 
критическая ошибка, можно вызвать самостоятельно - panic(), но чаще вызывается автоматически. Как только он читается в коде - defer сзади начинают разворачиваться и потом останавливается работа приложения
 ```
 func a() {
    defer fmt.Println("A1")
    defer fmt.Println("A2")
    b()
}

func b() {
    defer fmt.Println("B1")
    defer fmt.Println("B2")
    panic("boom")
}

B2 B1 A2 A1 panic: boom
 ```
## recover()
нужен, чтобы **перехватить `panic` и не дать программе завершиться**. Работает разумеется только в defer функции.
Обычно используют в HTTP-серверах, чтобы паника в одном запросе не уронила весь сервер, но panic в разы дороже чем вернуть ошибку errors.New поэтому его нельзя допускать
