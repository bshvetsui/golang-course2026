Terraform  в отличии от Ansible управляет уже существующей инфраструктурой на проекте.

**Провайдер** - облако которое предоставляет API для Terraform. Terraform в 99% случаев работает в облачных 

Основная сущность - файл tfstate в котором описана состояние инфраструктуры на момент последнего запуска. Его нельзя править вручную иначе будет configure drift - неожидаемое состояние для системы из за чего может случайно что то удалится
### Структура (упрощена)
```
terraform/
backend.tf    → где хранить state
providers.tf  → каким provider пользоваться
main.tf       → что создать
variables.tf  → переменные
outputs.tf    → выходные переменные
```
### Как блокировать изменения tfstate
Надо прописать `use_lockfile   = true` в backend.tf
``` backend-tf
terraform {
    backend "s3" {
      bucket         = "backet_name"
      encrypt = true
      key            = "dev/network/terraform.tfstate"
      region         = "us-east-1"
      use_lockfile   = true  # Enable native S3 locking
    }
  }
```
