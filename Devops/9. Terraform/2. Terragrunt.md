**Terragrunt — это обёртка над Terraform.** Сам он инфраструктуру не создаёт: он организует Terraform-конфиги .hcl, в них просто прописаны где брать переменные 

Например вместо повторяющейся структуры контуров .tf которые по сути копипаст с разными переменными
```
dev/main.tf
stage/main.tf
prod/main.tf
```
у нас получается один .tf файл с разными конфигурациями
```
               ┌── dev/terragrunt.hcl
Terraform      ├── stage/terragrunt.hcl
module ────────┤
               └── prod/terragrunt.hcl
```
В коде пример:
```.tf
# modules/network/main.tf

resource "yandex_vpc_network" "this" {
  name = var.name
}
```

```
# modules/network/variables.tf

variable "name" {
  type = string
}
```
а в terragrunt мы их прокидываем
для dev:
```
# live/dev/network/terragrunt.hcl

terraform {
  source = "../../../modules/network"
}

inputs = {
  name = "dev-network"
}
```
для prod:
```
# live/prod/network/terragrunt.hcl

terraform {
  source = "../../../modules/network"
}

inputs = {
  name = "prod-network"
}
```
