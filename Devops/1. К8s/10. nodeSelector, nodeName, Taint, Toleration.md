nodeSelector, nodeName Это способы определить, **на каком Node должен запуститься Pod**.
```yml
spec:
  nodeSelector: # критерии выбора ноды для запуска
    disktype: ssd # Выбираем только ноды с ssd
```

```yml
spec:
  nodeName: kube-01 # Выбираем конкретную НОДУ по НАЗВАНИЮ
```

**Taint** — это ограничение на Node. Оно говорит: **не размещать здесь Pod'ы, которые не умеют терпеть этот taint**.

**Toleration** — настройка Pod'а, которая разрешает ему запускаться на Node с соответствующим taint.
1. **NoSchedule**
	Новые Pod'ы без подходящего toleration **не будут размещены** на этой Node. Уже запущенные Pod'ы останутся.
2. **PreferNoSchedule**
	Kubernetes **постарается не размещать** здесь Pod без toleration, но если других вариантов нет — может разместить.
3. **NoExecute**
	Pod'ы без подходящего toleration **не смогут запускаться** на Node, а уже работающие Pod'ы без toleration **будут удалены с неё**.
ставится так:
`kubectl taint nodes worker-01 dedicated=gpu:NoSchedule`

а tolerations: прописываются в yaml после spec:
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: app
spec:
  containers:
    - name: app
      image: nginx

  tolerations: # вот здесь, после spec:
    - key: "dedicated"
      operator: "Equal"
      value: "gpu"
      effect: "NoSchedule"
