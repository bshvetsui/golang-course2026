**Requests** — ресурсы, которые K8s учитывает при выборе Node для пода.
**Limits** — максимальное потребление ресурсов контейнером.
```yml
resources:
  requests: # тут реквесты
    cpu: 50m
    memory: 128Mi
  limits: # тут лимиты
    cpu: 500m
    memory: 256Mi
```
**QoS** - уровни приоритета выживаемости подов при OOMkill 
1. **Guaranteed** — `requests = limits`, самый защищённый.
2. **Burstable** — ресурсы заданы частично или `requests < limits`.
3. **BestEffort** — `requests` и `limits` вообще не заданы, самый низкий приоритет.
```
BestEffort  → первые кандидаты
Burstable   → следующие
Guaranteed  → в последнюю очередь
```
