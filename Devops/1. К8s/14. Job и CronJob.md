**job** - Одноразовая задача. Создает один или несколько подов, и ожидает их успешного завершения.
Если что-то завершается с ошибкой, то джоб бдует запускать новые копии, пока количество успешных выполнений не будет равно заданному.
Типовые примеры:
    - Запуск тестов
    - Применение миграций базы данных
    - Выполнение одноразовых скриптов

1. **Backofflimit** - максимальное количество попыток. Джоб после этого не будет пытаться что-то делать. И новых контейнеров не создаёт.
 2. **activeDeadlineSecond** - таймлайны для джобы. Больше ничего создаваться не будет.
3. **ttlSecondsAfterFinished** - максимальное время жизни завершенного джоба. Нужна для того, чтобы человек мог успеть посмотреть результат. В контейнере логи глянуть например.
4. **restartPolicy** - регулируем перезапускать или нет. Но самому контейнеру за этим следить не надо. Поэтому Never
```
apiVersion: v1
kind: Job # вызываем job
metadata:
  name: pi

spec:
  completions: 8                 # сколько успешных выполнений нужно
  parallelism: 4                 # сколько Pod могут выполняться параллельно
  backoffLimit: 4                # максимум повторных попыток при ошибке
  activeDeadlineSeconds: 60      # максимальное время выполнения Job
  ttlSecondsAfterFinished: 100   # удалить завершённый Job через 100 сек

  template:
    spec:
      containers:
        - name: pi
          image: perl
          command: ["perl", "-Mbignum=bpi", "-wle", "print bpi(2000)"]

      restartPolicy: Never
```

**CronJob** - автоматически создаёт поды по расписанию. Расписание задаётся в крон-формате.
Применение:
    - Рассылки писем, уведомлений
    - Бэкапы
    - Выполнение задач в менее нагруженное время
```
kind: CronJob # выбираем крон джобу
metadata:
  name: hello

spec:
  schedule: "*/1 * * * *"        # запуск каждую минуту

  jobTemplate:                   # шаблон создаваемого Job
    spec:
      template:
        spec:
          containers:
            - name: hello
              image: busybox
              args:

          restartPolicy: OnFailure # при падении рестартим
```
