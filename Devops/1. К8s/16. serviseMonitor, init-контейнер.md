1. Prometheus Operator постоянно отслеживает ресурсы ServiceMonitor (он нужен для этого) и Services в Kubernetes.
2. Из выбранных сервисов он извлекает информацию об endpoint'ах:
```yaml
apiVersion: monitoring.coreos.com/v1
kind: ServiceMonitor
metadata:
  name: my-app-monitor
  namespace: default
  labels:
    app: my-app
spec:
  selector:
    matchLabels:
      app: my-app-service # Выбрать сервисы с лейблом app: my-app-service
  endpoints:
  - port: http-metrics   # Имя порта в спецификации сервиса
    path: /internal/metrics # Путь к метрикам
    interval: 30s          # Собирать каждые 30 секунд
```

### init-container 
Специальный контейнер в поде, который завершает свою работу до старта основных контейнеров пода. Используется для:
1. Инициализация среды перед запуском основного приложения.
2. Загрузка конфигурации или скриптов.
