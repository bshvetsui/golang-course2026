Посмотреть процессы - `ps aux`
```
PID   → ID самого процесса. Расшифровывается "process ID"
PPID  → PID родительского процесса, у процессов часто есть вложенность
```
Процессам нужны идентификаторы PID чтобы взаимодействовать с ними через команды, убивать например.
## Сигналы процессорам
Их порядка 30 суммарно, самые важные:
```
SIGTERM  15 → корректно завершиться
SIGKILL   9 → kernel немедленно убивает
SIGINT    2 → interrupt, через Ctrl+C прервать
SIGHUP    1 → часто reload конфигурации
SIGSTOP  19 → остановить
SIGCONT  18 → продолжить
```
Синтаксис:
```bash
kill -TERM 1234 # убиваем процесс с PID 1234. Прравильно
kill 1234 # тоже самое, sigterm
pkill firefox # тоже самое, sigterm по названию процесса 
```
Если процесс завис и не реагирует:
```sh
kill -KILL 1234 # быстро, но будут проблемы
```

### Зомби и сироты
Процессы дети при завершении должны передавать exit code. если мы делаем sigkill то ребенок становится **зомби процессом**, убивать его бессмысленно, он не потребляет ресурсы, но присутсвует в таблице **ps** с пометкой **Z**. Работает пока родитель не обработает его.

Процесс сирота - родитель у него завершился, управляется процессом **init** (PID 1) и завершается нормально
