### 1. Kubernetes
**Подключение:** `kubelet/cAdvisor + kube-state-metrics + control-plane → Prometheus → Grafana`; часто используют `kube-prometheus-stack`.
**Смотреть:** Nodes CPU/RAM/disk/Ready; Pods CPU/RAM/restarts/OOMKilled/Pending; Deployments desired vs available replicas; PVC usage.
**Алерты:** Node NotReady, CrashLoop/OOMKilled, pod долго Pending, deployment unavailable, CPU throttling, memory/PVC/disk заканчиваются.
### 2. Go-сервис
**Подключение:** `Go /metrics → Prometheus → Grafana`; для полной observability: `Go → OTLP → Alloy/OTel Collector → Prometheus/Loki/Tempo`.
**Смотреть:** RED — `Rate, Errors, Duration`; p95/p99 latency, error rate, goroutines/heap, DB/Redis/Kafka dependency latency.
**Алерты:** service down, error rate вырос, p95/p99 высокий, memory/goroutines постоянно растут, DB pool исчерпан.
### 3. PostgreSQL
**Подключение:** `Postgres → postgres_exporter/Alloy → Prometheus → Grafana`; либо `Grafana → PostgreSQL datasource → SQL` для данных из таблиц/бизнес-метрик.
**Смотреть:** connections/max, query latency, locks/deadlocks, replication lag, DB/disk size.
**Алерты:** connections >80–90%, replication lag, deadlocks, long queries, disk заканчивается.
### 4. Redis
**Подключение:** `Redis → redis_exporter/Alloy → Prometheus → Grafana`.
**Смотреть:** memory/maxmemory, hit/miss ratio, evictions, command latency, replication lag.
**Алерты:** memory почти закончилась, evictions растут, latency высокая, replica отстаёт.
### 5. Kafka
**Подключение:** `Kafka JMX → Alloy/JMX exporter → Prometheus → Grafana`; consumer lag часто через `kafka_exporter`.
**Смотреть:** broker health, consumer lag, offline/under-replicated partitions, produce/consume rate, disk.
**Алерты:** broker down, lag постоянно растёт, offline partitions >0, under-replicated partitions >0, disk заканчивается.
### 6. RabbitMQ
**Подключение:** включить `rabbitmq_prometheus`; RabbitMQ отдаёт `/metrics` обычно на `:15692` → `Prometheus → Grafana`.
**Смотреть:** queue length, `ready/unacked`, consumers count, publish vs consume rate, memory/disk.
**Алерты:** очередь постоянно растёт, consumers=0, unacked растёт, consume медленнее publish, node/memory/disk alarm.
### 7. ClickHouse
**Подключение:** `ClickHouse /metrics → Prometheus → Grafana`; либо `Grafana → ClickHouse datasource → system.* / SQL`.
**Смотреть:** query latency/errors, CPU/memory/disk, parts/merges, replication lag.
**Алерты:** disk почти заполнен, errors/p99 растут, слишком много parts, replication queue растёт.
