Нужен чтобы через файлы конфигов описывать что надо сделать с конкретной сущностью
Это может быть: 
1. выдача прав новому девопсу на нодах где он будет работать - прокидывание ssh, конкретные права в линуксе и т.п
2. Тоже самое при удалении пользователя - разрываем ssh подключения, убираем всю информацию и доступы
3. Установка новых пакетов на каждый сервер через apt в линуксе
4. создание темплейта разворачивания воркер ноды при расширении проекта. :
   ```
disable swap
install containerd
configure containerd
install kubelet
install kubeadm
install kubectl
load kernel modules
configure sysctl
configure certificates
join cluster
   ```
Делаем через ансибл потому что если в процессе упадет нода - то у нас уже будет темплейт и мы сможем сделать тоже самое вместо того чтобы заново прописывать команды вручную.
это Называется **идемпотентность**

Скрипты bash в таких случаях не подойдут - они всегда ломаются и приходится строить логические ветвления через if. В ансибл все делается через 1 .yml файл короткий, и потом может применится много раз

### pull/push модель
**Pull**-модель преполагает, что управляемые хосты подтягивают инструкции с мастер-сервера.

**Push**-модель реализует подход, когда инструкции по желанию или по событию доставляются с управляющего на управляемые хосты.

Ansible чаще всего используется для push-модели управления, но умеет и pull-модель.
