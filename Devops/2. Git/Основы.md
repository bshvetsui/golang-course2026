это программа, которая сохраняет историю изменений кода и позволяет нескольким разработчикам работать над проектом, не перезаписывая работу друг друга.
Git работает локально на компьютере. GitLab — сервер, куда Git-репозитории отправляют для совместной работы.

**Ветка в Git — это отдельная линия изменений проекта.**
1. Есть основная ветка `main` — стабильный код.
2. Разработчик создаёт свою ветку, например `feature-login`.
3. Меняет код там, не ломая `main`.
4. Когда работа готова, изменения сливают обратно в `main`.  
   
## Основные команды 
1. git commit - сохраняем состояние. Можно делать сколько угодно, когда угодно, как чувствуешь что хочешь сохранить. 
2. git merge - соединить ветки, просто закидывая свои коммиты сверху 
3. git rebase - соединить ветки, но с сохранением порядка по дате и времени, твои коммиты могут быть в середине истории коммитов в финале
4. git cherry-pick - перекинуть коммиты с одной ветки на другую 
5. git pull - получить изменения с Gitlab или другого remote репозитория (BitBucket например)
6. git push - отправить ветку/ новые коммиты в ней в Gitlab
7. git fetch  - проверить есть ли новые изменения чтобы сделать pull

## Как лучше пользоваться
писать вручную в консоль долго, давно есть лучше варианты
1. Github desktop/ Git Kraken. Просто ui где все команды это удобные кнопки
2. Попросить CLI агента закоммитить и запушить merge request. 
   
## Merge Request 
это раздел в гитлаб который перед влитием в ветку разработчик создает, назначает ревьюера и происходит code review. Удобно показываются все коммиты и изменения которые разработчик вносит в код.
