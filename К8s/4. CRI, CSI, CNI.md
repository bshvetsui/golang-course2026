1. **CRI (Container Runtime Interface)** — интерфейс между `kubelet` и container runtime. Нужен, чтобы Kubernetes мог запускать/останавливать контейнеры. Пример: `containerd`
    `kubelet → CRI → containerd → container`

2. **CSI (Container Storage Interface)** — интерфейс подключения внешнего хранилища к Kubernetes. Через него создаются/подключаются диски для `PV/PVC`. Примеры: `AWS EBS CSI`, `Ceph CSI`, `NFS CSI`.  
	`PVC → StorageClass → CSI → storage`

3. **CNI (Container Network Interface)** — интерфейс подключения Pod к сети. Выдаёт `PodIP`, создаёт сетевой интерфейс, настраивает маршрутизацию и иногда `NetworkPolicy`. Примеры: `Cilium`, `Calico`, `Flannel`.  
    `Pod → CNI → сеть`  

Запоминалка: **CRI = контейнер | CNI = сеть | CSI = диск**.
