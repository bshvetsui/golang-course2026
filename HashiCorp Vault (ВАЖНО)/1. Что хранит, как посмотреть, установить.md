## Vault - самый распространенный способ хранить очень важные данные.
Есть секреты в кубернетесе, но они просто шифруют данные, их можно расшифровать. Vault хранит данные очень защищенно.
в Вольте хранятся креды (логины и пароли) для PostgreSQL, Kafka, Redis и т.п. Некоторые токены для доступа. 
Логины и пароли пользователей лежат в самой БД.

## Как посмотреть данные 
Логинишься через LDAP/OIDC (методы авторизации, см. статью здесь) 
либо заходишь на `https://vault.company.local:8200/ui` (там прям ui интерфейс)
либо пишешь в консоли `vault secrets list`

## Как установить
через helm (менеджер пакетов) 
`helm repo add hashicorp https://helm.releases.hashicorp.com`
## Пример прокидывания значения из Vault в прод
1. Pod запускается под ServiceAccount, например `backend-prod`.
2. Vault проверяет ServiceAccount и выдаёт Pod’у временный Vault-токен. Его обычно обслуживает Vault Agent, а не само Go-приложение.
3. Vault получает запрос к `database/creds/backend`.
4. Vault создаёт в PostgreSQL временного пользователя, например `v-backend-abc123`, с ограниченными правами и TTL.
5. Vault Agent кладёт логин и пароль в файл внутри Pod:
Пример yaml:
```yaml
serviceAccountName: backend-prod // имя юзера как в линуке. Нужно для выдачи прав
annotations:
  vault.hashicorp.com/agent-inject: "true"
  vault.hashicorp.com/role: "backend-prod"
  vault.hashicorp.com/agent-inject-secret-postgres.json: "database/creds/backend"
  vault.hashicorp.com/agent-inject-template-postgres.json: |
    {{- with secret "database/creds/backend" -}}
    {
      "username": "{{ .Data.username }}",
      "password": "{{ .Data.password }}"
    }
    {{- end }}
```
