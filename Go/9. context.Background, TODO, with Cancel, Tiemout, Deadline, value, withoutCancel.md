нужен, чтобы остановить всю связанную работу, когда она больше не нужна
## Корневые контексты

|Функция|Что делает|Пример|Применение|
|---|---|---|---|
|**`context.Background()`**|Главный пустой контекст|`ctx := context.Background()`|`main`, запуск сервера или воркера|
|**`context.TODO()`**|Временная заглушка, когда нужный контекст ещё не определён|`ctx := context.TODO()`|Разработка и постепенный рефакторинг|
## Создание дочерних контекстов

| Функция             | Что делает                                              | Пример                                                                | Применение в проде                                     |
| ------------------- | ------------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------ |
| `WithCancel`        | Ручная отмена                                           | `ctx, cancel := context.WithCancel(parent)`                           | Остановить горутины при ошибке или завершении операции |
| `WithCancelCause`   | Ручная отмена с причиной                                | `ctx, cancel := context.WithCancelCause(parent); cancel(err)`         | Сохранить точную причину остановки для логов           |
| `WithTimeout`       | Отмена через заданное время                             | `ctx, cancel := context.WithTimeout(parent, 2*time.Second)`           | Ограничить время запроса к БД или API                  |
| `WithTimeoutCause`  | Таймаут с собственной причиной                          | `ctx, cancel := context.WithTimeoutCause(parent, 2*time.Second, err)` | Понятная ошибка при превышении времени                 |
| `WithDeadline`      | Отмена в конкретный момент                              | `ctx, cancel := context.WithDeadline(parent, deadline)`               | Завершить задачу до общего дедлайна                    |
| `WithDeadlineCause` | Дедлайн с собственной причиной                          | `ctx, cancel := context.WithDeadlineCause(parent, deadline, err)`     | SLA, очереди и фоновые задачи                          |
| `WithValue`         | Добавляет служебное значение                            | `ctx := context.WithValue(parent, key, value)`                        | Request ID, Trace ID, авторизация                      |
| `WithoutCancel`     | Не наследует отмену родителя, но сохраняет его значения | `ctx := context.WithoutCancel(parent)`                                | Аудит или логирование после завершения HTTP-запроса    |

## Основные методы `context.Context`

| Метод        | Что делает                                          | Пример                           |
| ------------ | --------------------------------------------------- | -------------------------------- |
| `Done()`     | Возвращает канал, который закрывается при отмене    | `case <-ctx.Done():`             |
| `Err()`      | Возвращает `Canceled`, `DeadlineExceeded` или `nil` | `err := ctx.Err()`               |
| `Deadline()` | Возвращает время дедлайна и наличие дедлайна        | `deadline, ok := ctx.Deadline()` |
| `Value(key)` | Получает значение из контекста                      | `requestID := ctx.Value(key)`    |

## Дополнительные функции

| Функция     | Что делает                               | Пример                                    | Применение в проде                       |
| ----------- | ---------------------------------------- | ----------------------------------------- | ---------------------------------------- |
| `Cause`     | Возвращает подробную причину отмены      | `err := context.Cause(ctx)`               | Логи и диагностика ошибок                |
| `AfterFunc` | Запускает функцию после отмены контекста | `stop := context.AfterFunc(ctx, cleanup)` | Закрытие соединения или очистка ресурсов |

## Короткий пример из прода

```go
func getUser(parent context.Context, id int) error {
	ctx, cancel := context.WithTimeoutCause(
		parent,
		2*time.Second,
		errors.New("база не ответила за 2 секунды"),
	)
	defer cancel()

	err := database.QueryUser(ctx, id)
	if err != nil {
		log.Println("причина:", context.Cause(ctx))
		return err
	}

	return nil
}
```

## Главное правило

```go
ctx, cancel := context.WithTimeout(parent, 2*time.Second)
defer cancel() //cancel всегда нужно делать через defer
```

`defer cancel()` освобождает связанные с контекстом ресурсы, даже если операция завершилась раньше таймаута.
