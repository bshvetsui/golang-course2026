Базовые:
1. bool - true или false
2. string - последовательность байт в кодировке utf-8

Целочисленные:
1. int, int8/16/32/64 - знаковые целые числа (могут быть отрицательными)
2. uint, uint8/16/32/64 - беззнаковые целые числа
Размер `int` и `uint` зависит от системы — 32 или 64 бита.  
3. **byte** — алиас для `uint8`, используется для работы с сырыми данными  
4. **rune** — алиас для `int32`, представляет Unicode code point  
5. **uintptr** — беззнаковое целое, достаточное для хранения указателя  


  Числа с плавающей точкой: 
1. **float32** — 32-битное число с плавающей точкой (IEEE 754)  
2. **float64** — 64-битное число с плавающей точкой, используется по умолчанию  
3. **complex64, complex128** — комплексные числа с float32 и float64 компонентами  
  
## Составные типы  
  
1. **array** — массив фиксированной длины, является value type и копируется целиком при присваивании  
2. **Slice** — динамический массив, обёртка над underlying array с автоматическим ростом  
3. **Map** — хеш-таблица для хранения пар ключ-значение  
4. **struct** — набор именованных полей, основной способ создания пользовательских типов  
5. **Channel** — канал для коммуникации между горутинами  
  
## Ссылочные типы  
  
1. **pointer** — хранит адрес переменной, записывается как `*T`  
2. **function** — функции являются first-class citizens, их можно присваивать переменным и передавать как аргументы  
3. **Interface** — набор сигнатур методов, реализуется неявно  
  
## Zero values  
Каждый тип имеет zero value — значение по умолчанию при объявлении без инициализации:  
- **0** — для всех числовых типов  
- **false** — для `bool`  
- **""** — для string  
- **nil** — для pointer, slice, map, channel, function, interface  
  
## Приведение типов  
Go не допускает неявных преобразований. Даже между `int32` и `int64` требуется явное приведение через `T(value)`. Это предотвращает скрытые ошибки при потере точности или переполнении.
