## Роадмап входа в Node.js → NestJS

1. **База JavaScript для бэкенда**
    
    - области видимости, замыкания, `this`
        
    - прототипы и классы
        
    - модули: CommonJS и ESM
        
    - Promise, `async/await`
        
    - обработка ошибок
        
    - event loop, microtasks и macrotasks
        
2. **TypeScript**
    
    - типы, интерфейсы, type aliases
        
    - generics
        
    - union/intersection types
        
    - utility types
        
    - декораторы
        
    - `strict`-режим
        
    - отличие compile-time типов от runtime
        
3. **Внутренности Node.js**
    
    - устройство runtime: V8, libuv
        
    - event loop и его фазы
        
    - неблокирующий I/O
        
    - `process`, переменные окружения, сигналы
        
    - `Buffer`
        
    - `EventEmitter`
        
    - потоки: Readable, Writable, Transform
        
    - файловая система
        
    - таймеры
        
    - worker threads и child processes
        
    - ограничения однопоточной модели
        
4. **HTTP на чистой Node.js**
    
    - поднять сервер через модуль `http`
        
    - request/response lifecycle
        
    - headers, status codes, body
        
    - routing вручную
        
    - middleware как концепция
        
    - обработка JSON
        
    - graceful shutdown
        
5. **Устройство Node-проекта**
    
    - `package.json`
        
    - npm scripts
        
    - зависимости и devDependencies
        
    - ESM против CommonJS
        
    - `tsconfig`
        
    - сборка TypeScript
        
    - переменные окружения
        
    - линтер и форматтер
        
    - логирование
        
    - конфигурация приложения
        
6. **Основы NestJS**
    
    - modules
        
    - controllers
        
    - providers
        
    - dependency injection
        
    - services
        
    - DTO
        
    - decorators
        
    - application context
        
    - жизненный цикл приложения
        
7. **Обработка запросов в NestJS**
    
    - middleware
        
    - guards
        
    - interceptors
        
    - pipes
        
    - exception filters
        
    - порядок их выполнения
        
    - validation через DTO
        
    - собственные декораторы
        
8. **Архитектура NestJS**
    
    - разделение по feature-модулям
        
    - controller → service → repository
        
    - интерфейсы и injection tokens
        
    - dynamic modules
        
    - global modules
        
    - circular dependencies и способы их убрать
        
    - конфигурационные модули
        
    - избегать бизнес-логики в контроллерах
        
9. **Продвинутый NestJS**
    
    - lifecycle hooks
        
    - request-scoped providers
        
    - custom providers
        
    - factory providers
        
    - metadata и `Reflector`
        
    - platform adapters
        
    - создание собственных pipes, guards и interceptors
        
    - graceful shutdown
        
    - версионирование API
        
10. **Тестирование**
    

- unit-тесты сервисов
    
- мокирование зависимостей
    
- тестирование controllers
    
- `TestingModule`
    
- интеграционные тесты модулей
    
- e2e-тесты HTTP
    
- тестирование guards, pipes и filters
    

11. **Практические проекты**
    

- сначала HTTP-сервер на чистой Node.js
    
- затем маленький CRUD на NestJS
    
- затем приложение с авторизацией, ролями и валидацией
    
- затем модульный проект с несколькими доменными областями
    
- затем самостоятельно реализовать guard, interceptor, pipe и exception filter
    

12. **Что нужно понимать на выходе**
    

- почему Node.js хорошо работает с I/O, но плохо с тяжёлыми CPU-задачами
    
- как запрос проходит через NestJS
    
- как работает DI-контейнер
    
- чем middleware отличается от guard, pipe и interceptor
    
- когда использовать singleton, request scope и transient
    
- как проектировать модули без циклических зависимостей
    
- как корректно обрабатывать ошибки и завершать приложение
    

Оптимальный порядок: **JavaScript → TypeScript → внутренности Node.js → чистый HTTP → NestJS база → request lifecycle → архитектура → тесты → продвинутый NestJS**.
